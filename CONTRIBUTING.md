# Contributing

Thanks for helping with Freematics. Issues and pull requests are welcome; pull requests go against `dev`. Run the checks in [CLAUDE.md](CLAUDE.md) → "Validate" (or let CI run them), and add a line to `CHANGELOG.md` under `## [Unreleased]`. When you attach diagnostics (Settings → Devices & services → Freematics → ⋮ → Download diagnostics), they're safe to post: the webhook ID is redacted and no coordinates are included.
